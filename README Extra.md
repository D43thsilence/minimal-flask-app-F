## User Guide

Using this readymade exhibition creation tool is simple, as a user, all you need to do is type a description of the object you wish to create an exhibition for. Then you click the submit button. Then, the website will automatically generate a tombstone label of the object for its exhibition alongside an image of the described object in its exhibition space.

## IAE features & prompt rule translation

The IAE features I emphasized within the tombstone label and object description generation are its vocabulary and syntax.

For the vocabulary, most descriptions generated by the LLM properly emphasize space, interconnectivity, tension, they also highlight questions, subversion, transformation and encoding. Creating a poetic,flowing and lyrical description for the described object.

For the syntax, overly verbose sentences, the adverbial/double adverbial phrases that are typical of the IAE appear alongside pairing opposing terms/concepts together.

Suprisingly, I was able to acheive bringing the LLM to use this writing style by simply instructing it to use "sophisticated language and artistic terms" when writing its responses.

### how the image prompt is derived from the label

To facilitate the image generation feature's implementation in the code, the image prompt and the prompt that is behind the lablel's generation is the same. A single prompt is behind all of the website's generated content.

### a reflection on this question: why is a language model so fluent in this dialect?

I believe that the reason a language model is so fluent in this dialect is because it is reminiscent of low temperature and low top_p responses that are logical, straight to the point, and less emotive. Plus, due to the way LLMs divide words into tokens and the how max token constraint works. LLMs are already naturally quite verbose and the length of their response can easily be controlled. Another obvious reason why a language model would be fluent in this dialect would be its training data. As there is probably an uncountable amout of artistic texts and museum labels within the training data and the LLM's definitely have a large pool of references to pick terms & sentences from.
